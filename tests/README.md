# Backend Tests

## Overview

This directory contains automated tests for the Accessibility Audit API.

## Test File

- `server.test.js` – Tests the backend API endpoints.

## Test Coverage

1. Verifies that the home endpoint returns the expected welcome message.
2. Verifies that the health endpoint returns a successful server status.

## Run Tests

Open the terminal in the project root and execute:

```bash
cd server
npm test
```

## Expected Result

Both automated tests should pass if the API endpoints return the expected responses.
